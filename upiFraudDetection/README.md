# 💳 UPI Fraud Detection using Machine Learning

A Flask-based web application that detects whether a UPI transaction is **Fraudulent** or **Legitimate** using a trained Machine Learning model.

---

# 🚀 Features

- Upload transaction details
- Predict Fraud or Legitimate transaction
- Interactive Dashboard
- Charts & Visualizations
- Fast Prediction
- Simple UI

---

- Flask

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Md-Kaif534/UPI-Fraud-Detection.git
```

Move into project directory

```bash
cd UPI-Fraud-Detection
```

Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

Run the Flask application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
